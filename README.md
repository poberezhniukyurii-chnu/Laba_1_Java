# Лабораторна робота №1 — Основи мови Java

Дисципліна «Програмування мовою Java», ЧНУ імені Юрія Федьковича.
Виконав: Побережнюк Юрій Вікторович, група 241б.

**Варіант:** 14 (у завданні 1 лише 10 виразів, тому взято вираз №4)

## Завдання

| № | Головний клас | Що робить |
|---|---|---|
| 1 | `task1.Main` | Вираз №4 у трьох варіантах типів (дійсні/цілі вхідні дані та результат) |
| 2 | `task2.Main` | Найменший елемент масиву A, якого немає в масиві B (три способи) |
| 3 | `task3.Main` | Вектор X(n): сума модулів між першим і останнім додатними елементами рядка матриці |
| 4 | `task4.Main` | Вилучення з тексту слів, що починаються з голосної |

## Як запустити

**IntelliJ IDEA:** File → Open → папка `Laba_1_Java`. Якщо IDEA попросить JDK, натисни *Setup SDK* → *Download JDK* (підійде будь-яка версія від 8).
Для кожного завдання вже є конфігурація запуску — обери її у списку вгорі праворуч і натисни ▶.

**Командний рядок** (з кореня проєкту):

```
javac -encoding UTF-8 -d out src/task1/*.java src/task2/*.java src/task3/*.java src/task4/*.java
java -cp out task1.Main
```

Код сумісний з Java 8 і новішими.
